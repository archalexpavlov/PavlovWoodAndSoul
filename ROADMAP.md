## Этап 1 — минимальный сквозной продукт

```
—  1.1  Первый проект целиком     Domek_2: модель, документы, тексты
—  1.2  Сайт                      список проектов, 3D-вьювер, оплата
—  1.3  Генератор документов      отдельная система, принимает параметры
—  1.4  Учёт                      пять колонок: источник, скачал, купил, построил, цена
—  1.5  Первый построенный объект терраса у знакомых по проекту из конфигуратора
```

Цель этапа — не красота, а **возможность продать и измерить**.

**1.5 упирается в чужой календарь, поэтому начинается раньше остальных.** Материалы
за знакомыми, сборка за Алексом. Без построенного объекта нет фото для листинга —
Etsy требует результат, а не рендер, — нет видео сборки и нет отзыва. Договариваться
до того, как понадобится.

## Этап 2 — проверка спроса

```
—  2.0  Мелкие объекты-магниты    ящик для утвари, компостер, ворота — органика, не доход
—  2.1  Соцсети под версию 2      что переносится из v1, что снимается, что доснять
—  2.2  Своя тысяча долларов      реклама на выбранном рынке
—  2.3  Измерить                  цена лида, конверсия в оплату, доля построивших
—  2.4  Прочитать результат       четыре исхода, см. ниже
```

**2.0 идёт первым номером, потому что это бесплатный трафик, а 2.2 — платный.**
Мелкий объект делается за вечер и ищется органически в разы чаще крупного. На нём
не зарабатываем — им приводим людей к инструменту. Ящик для садовой утвари: на польском
рынке предложений мало.

⚠️ **Условие, без которого полка не работает.** Мелочь тянет трафик, только когда купить
эквивалент раздражает или дорого. У шведов компостер собрал 25 тыс. просмотров,
а садовый стул — тысячу с одним лайком: стул стоит 30 € в гипермаркете.
**В садовую мебель не идти.** Цифры — `docs/benchmarks.md`.

**Как читается результат — решено заранее:**

```
лидов нет вообще          оффер не считывается — переписать обещание
лиды есть, продаж нет     цена или доверие — тестировать и то и другое
продажи есть, CAC > чека  канал не тот — пробовать другой
продажи есть, CAC < чека  работает — идти за деньгами
```

Правило: не вливать вторую тысячу в тот же канал с тем же оффером, не поняв,
который из четырёх случаев перед нами.

# Порядок, который следует из данных

CB Insights разобрал 431 закрывшийся стартап: корневые причины — отсутствие product-market fit
(43%), неудачный тайминг (29%), несходящаяся юнит-экономика (19%). «Кончились деньги» у 70%,
но это финал, а не причина.

Отсюда очередность: **сначала PMF, потом юнит-экономика, потом всё остальное.**
Этапы 0–2 целиком про это. Мультиязычность, AR, партнёрства и переговоры с сетями —
после, потому что ни одно из них не спасёт, если первые два не сошлись.

Тайминг сейчас работает на нас: комфорт дорожает, DIY растёт, блокированная застройка
расходится без террас. Это не вечное окно.

# Структура проектов

```
Pavlov - wood&soul/        этот проект: бизнес, маркетинг, стратегия
  ROADMAP.md               карта
  docs/                    решённые вопросы, по одному файлу
  HANDOFF_dev.md           пакет передачи в разработку
  .dev/                    рабочий слой агента
```

Дочерние проекты (программный продукт, вспомогательные инструменты) заводятся **рабочей
папкой внутри этого репозитория** — тогда агент дочернего проекта видит этот `CLAUDE.md`
и `ROADMAP.md` автоматически, Claude Code читает контекст вверх по дереву. Бизнес-решения
доступны сверху вниз, технический контекст наверх не протекает.
