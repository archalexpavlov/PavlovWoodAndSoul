# PAVLOV — контекст для Claude Code

Алекс Павлов под Новым Сончем. **Версия 2, с 11 октября 2026.**

**Продукт — проекты, а не стройка.** Он разрабатывает придомовые конструкции (террасы, детские
домики, дальше теплицы и сауны) и отдаёт их людям, которые строят сами. Проект выглядит как
инструкция IKEA: конкретные артикулы, узлы, порядок работ. Производство он на себя не берёт.

Доход приходит не с проектов: партнёрство с сетями DIY, роялти за лицензию линейки производителю,
платная расширенная документация. Рынок — Европа, не Польша.

Прежняя модель (объекты на заказ, локальный рынок, доход с человеко-часов) закрыта: потолок
2–3 тыс. USD в месяц, расширения нет. Её контекст — в `.dev/ARCHIVE_v1.md`, в работе не используется.

## Этот проект — бизнес и маркетинг

**Разработка вынесена в отдельный проект Claude Code.** Пакет передачи — `HANDOFF_dev.md`
в корне. Сюда технические решения попадают, только если меняют продукт или сроки.

Здесь: бизнес-план, позиционирование, тексты, соцсети, работа с инвестором.

**Дочерние проекты заводятся рабочей папкой внутри этого репозитория** — тогда их агент видит
этот файл и `ROADMAP.md` автоматически: Claude Code читает контекст вверх по дереву.
Бизнес-решения доступны сверху вниз, технический контекст наверх не протекает.

## Инфраструктура — собрана, не переисследовать

- **Имя продукта — Ritfab**, решено 1 ноября 2026. Отбор и проверки — `docs/naming.md`
- **Домены Ritfab:** `ritfab.com` основной (куплен в Cloudflare Registrar),
  `ritfab.eu` и `ritfab.de` (куплены в Namecheap) отдают 301 на `.com`.
  NS всех трёх — `archer.ns.cloudflare.com`, `ollie.ns.cloudflare.com`.
  Редирект сделан правилом Cloudflare Redirect Rules, не переадресацией регистратора:
  у Namecheap нет сертификата на эти домены, `https` ломался бы.
  В зонах `.eu` и `.de` стоят две `A` на `192.0.2.1` с проксированием (адрес фиктивный,
  трафик перехватывает правило), плюс `v=spf1 -all`, `v=DMARC1; p=reject;` и нулевой `MX`
  с точкой — домены почту не возят, подделать отправителя нельзя
- `ritfab.com` пока пустая зона без A-записи: редиректы ведут туда, но сайта там ещё нет
- **Домен `alexpavlov.pl`**, DNS у регистратора aftermarket, NS не переезжали
- **Почта `kontakt@alexpavlov.pl`** — ящик у регистратора, Sieve шлёт копию в Gmail.
  Отправка через `smtp.aftermarket.pl:587`
- **Сайт** — заглушка на Netlify из репозитория `PavlovSite`, `https://alexpavlov.pl`
- Незакрытый хвост: DKIM подписывается доменом регистратора, не его
