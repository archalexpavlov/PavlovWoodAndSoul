# PAVLOV — контекст для Claude Code

Личный бренд Алекса Павлова под Новым Сончем. **Продукт один: детские домики под заказ.**
Модель авторская — я придумываю проекты, клиент выбирает из моих, дальше адаптация под участок и стройка.
Терраса и сауна во дворе показываются как портфолио, купить их никто не предлагает.

Работа идёт над текстами, фотографиями, эскизами и планом публикаций. Это не код.

**Первым делом прочитать `.dev/RULES.md` целиком** — единственный источник правил.
Потом `.dev/STATE.md` — где стоим прямо сейчас и что делали последним.

| Что нужно | Единственное место |
|---|---|
| как я работаю, порядок начала сессии | `.dev/RULES.md` |
| где стоим сегодня, чем заняты | `.dev/STATE.md` |
| что сделано и что сломалось | `.dev/progress.md` |
| что решено и что отклонено, с причинами | `.dev/CONTEXT.md` |
| позиционирование, цены, банк фраз | `Instagram/PAVLOV_brand_doc.md` |
| план публикаций | `Instagram/PAVLOV_content_plan.xlsx` |

## Основной цикл

Алекс пишет заметки прямо в ячейках таблицы → просит сформулировать, перевести, переписать →
**я правлю эту же таблицу на месте** → он смотрит дифф и пушит.

Его правки читать через `git diff -- Instagram/PAVLOV_content_plan.xlsx`: подключён textconv, дифф идёт
по ячейкам. Файл целиком не выгружать.

## Инфраструктура — собрана, не переисследовать

- **Домен `alexpavlov.pl`**, DNS у регистратора aftermarket, NS не переезжали
- **Почта `kontakt@alexpavlov.pl`** — ящик у регистратора, Sieve-фильтр шлёт копию на
  `kontakt.alexpavlov@gmail.com`, оттуда пуш. Отправка из Gmail через `smtp.aftermarket.pl:587`
- **Сайт** — заглушка на Netlify из репозитория `PavlovSite`, `https://alexpavlov.pl`, `www` редиректит
- Незакрытый хвост: DKIM подписывается доменом регистратора, не его. Подробности в `STATE.md`

## Чего не делать

- Не заводить файлов и инструментов, которые не понадобились.
- Не писать того, чего не было: ни выдуманных правил, ни фактов об объектах, которых он не говорил,
  ни сцен из его жизни.
- Не добавлять шагов в его процесс.
- Не ставить трейлеров и упоминаний агента в сообщениях коммитов.
- Не переоткрывать решённое — сверяться с `.dev/CONTEXT.md`.
- Текст с обратными слешами писать только через Write/Edit: heredoc их съедает.
- Не расширять охват списками — весь месяц ушёл на сужение фокуса. Узко лучше.

Не понял задачу — переспросить. Цифры, цены и контакты заполняет он сам.
