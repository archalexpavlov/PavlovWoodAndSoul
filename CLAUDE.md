# PAVLOV — контекст для Claude Code

Личный бренд Алекса Павлова: деревянные альтаны, детские домики, площадки под Новым Сончем.
Задача — запустить пустой Instagram `@pavlov.pl` и довести до первых заказов.
Работа идёт над текстами, фотографиями и планом публикаций.

**Первым делом прочитать `.dev/RULES.md` целиком** — единственный источник правил.

| Что нужно | Единственное место |
|---|---|
| как я работаю, порядок начала сессии | `.dev/RULES.md` |
| где стоим сегодня | `.dev/STATE.md` |
| что сделано и что сломалось | `.dev/progress.md` |
| что решено и что отклонено по бренду | `Instagram/PAVLOV_kontekst.md` |
| позиционирование, цены, банк фраз | `Instagram/PAVLOV_brand_doc.md` |
| план публикаций | `Instagram/PAVLOV_content_plan.xlsx` |

## Основной цикл

Алекс пишет заметки прямо в ячейках таблицы → просит сформулировать, перевести, переписать →
**я правлю эту же таблицу на месте** → он смотрит дифф и пушит.

Его правки читать через `git diff -- Instagram/PAVLOV_content_plan.xlsx`: подключён textconv, дифф идёт
по ячейкам. Файл целиком не выгружать.

## Два слоя

- **Его** — `Instagram/`, `Realizacje/`, `Logo/`, `Pomysły/`. Проектный git, уходит на GitHub.
- **Мой** — `.dev/`. Свой локальный git без remote, исключён через `.git/info/exclude`.
  Правила, состояние, журнал, мои инструменты.

## Чего не делать

- Не коммитить в проектный репозиторий — он смотрит и пушит сам.
- Не заводить файлов и инструментов, которые не понадобились.
- Не писать того, чего не было: ни выдуманных правил, ни фактов об объектах, которых он не говорил.
- Не добавлять шагов в его процесс.
- Не ставить трейлеров и упоминаний агента в сообщениях коммитов.
- Не переоткрывать решённое — сверяться с `PAVLOV_kontekst.md`.
- Текст с обратными слешами писать только через Write/Edit: heredoc их съедает.
